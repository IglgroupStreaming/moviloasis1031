# 🏜️ Radio Oasis FM 103.1 MZ - Simulador Estudio-Reportero

Simulador interactivo P2P para comunicación entre estudio y reportero móvil.

## 🚀 Demo en vivo

Abre `estudio.html` para el panel de control y comparte el enlace generado con el reportero.

## 📱 Características

- **Estudio**: Control total sobre el reportero (Cortar, Listo, Atención, Al Aire)
- **Reportero**: Interfaz tipo móvil con vúmetro y botones de acción
- **Comunicación P2P simulada** mediante localStorage
- **Alertas en tiempo real** entre ambos paneles
- **Interfaz profesional** con temática Radio Oasis FM

## 🔧 Cómo usar

1. Abre `estudio.html` en una ventana
2. Copia el enlace generado
3. Abre `reportero.html?estudio=XXX` en otra pestaña o dispositivo
4. Comienza la simulación

## 📡 Tecnologías

- HTML5, CSS3, JavaScript
- localStorage para comunicación
- Diseño responsive
